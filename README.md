# Tensor Contraction

This repo contains the vitis project corresponding to the hls implementation of the tensor contraction part for a quantum circuits simulation toolchain, which was developed as a project for the High Performance Processors and Systems course, held by Politecnico di Milano during AY 2023-24.
The software responsible for the rest of the toolchain, along with its documentation, can be found at [HPPS24-Quantum-Simulation](https://github.com/federico123579/HPPS24-Quantum-Simulation).

## Repository structure

- `analysis/`: contains code to do time and performance benchmarks of the kernels

- `deliverables/`: contains report of the project

- `report`: contains latex source of the report

- `scripts`: contains scripts to build the report and the vitis makefiles

- `src/`: contains source code, including host code, hls kernels, tests and their utilities
    - `host/`: contains host code, to perform circuit simulation, which has been broken down by the compiler into a sequence of tensor expansions and matrix multiplications (thus the relative calls to the kernels)
    - `kernel/`: contains kernels source code
        - `matrix-multiplication`: kernel for the tensor expansion
        - `tensor-expansion/`: kernel for the tensor contraction
